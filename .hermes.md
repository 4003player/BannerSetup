# BannerSetup

**Wide-format banner setup tool** — takes uploaded artwork and generates print-ready PDFs with proper bleed, TrimBox/BleedBox metadata, and setup sheets for the shop floor.

**Live:** https://4003player.github.io/BannerSetup/  
**Repo:** https://github.com/4003player/BannerSetup.git  
**Stack:** Single-file `index.html` (~2,550 lines), no build step, GH Pages hosted.

## Architecture

- **pdf-lib** — generates output PDFs (setup sheets + print-ready files)
- **PDF.js** — renders uploaded PDFs for preview
- **jsPDF** — secondary PDF generation (preview PDFs)
- **UTIF.js** — TIFF decoding
- Local copy of `pdf-lib.min.js` (not CDN)

## Key Features

- Face/back artwork handling for double-sided banners
- Per-side input bleed from TrimBox — NEVER average the bleeds
- TrimBox = material edge (including pockets/hems)
- BleedBox written to output for downstream tools (Proofmaker, Imposer)
- Setup sheet generation with dimensions, bleed info, finishing notes
- Print-ready PDF with proper `useObjectStreams: false` for Caldera RIP compatibility

## Critical Rules

1. **TrimBox is the material edge** — includes pockets/hems; it is NOT the visible area
2. **Per-side bleed** — each side (top/right/bottom/left) has its own bleed value derived from TrimBox. NEVER average them
3. **`useObjectStreams: false`** — required for Caldera RIP compatibility on all pdf-lib output
4. **Canvas cap 4000px** — max dimension for `toDataURL()` → `atob()` → `Uint8Array` pipeline
5. **`numVal()` helper** — Safari input parsing quirk
6. **`parsePDF()` copies bytes before `PDFDocument.load()`** — pdf-lib's `load()` detaches the ArrayBuffer

## Relationship to Other Tools

- Output PDFs include TrimBox/BleedBox metadata that Proofmaker and Imposer read
- Same Apple light theme as all other WAC tools
